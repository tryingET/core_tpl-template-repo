## Slices in order

1. **Observational instrumentation and condition check.** New test-owned timing
   runner plus opt-in bindings in the three unittest call sites and nested upgrade
   caller; timestamp existing generation phases. Scheduling/assertions stay unchanged.
   Run serial baseline and a fresh/changed-order condition, compare exact identities
   and outcomes; investigate any disagreement before restructuring.
2. **Measure and repair harness ambiguity.** Diagnose doctor-to-quiet-grep broken
   pipes in isolation; ensure the command genuinely succeeds before its output
   assertion. Keep the compatible public ROCS pin and actual integration execution.
3. **Extract only proven-independent units.** Fresh processes, never threads sharing
   `os.environ`, umask, module mocks or the source helper's active-process state.
   Keep stateful rerender histories and per-generated-repository gate sequences serial.
   Separate cheap/static work from expensive real integration without dropping either.
4. **Reuse only measured immutable setup.** Historical/current L1 seed renders are
   candidates, not accepted optimizations. Key exact source/runtime/answers and copy
   independent writable trees/history; never cache a passing lifecycle result.
5. **Balance <=6 hosted jobs from measured durations.** Independent full-history
   source checkouts avoid adversarial worktree common-directory interference. Account
   for class setup, cold provisioning, aggregation and runner-minute cost. Preserve
   full local owner verification and explicit coverage accounting.
6. **Narrow/wide equivalence and exact-SHA hosted proof.** Repeat under second
   conditions, independently inspect, verify committed paths, push only the scoped
   performance branch and inspect every hosted job to completion. A proposal or local
   speed proxy is not the <=15-minute hosted result.

## Risks and stop conditions

- Parallel source writes, shared Git common directories, fixture reuse with embedded
  absolute paths/authority, global mocks, mutable caches, bytecode, unexpected test
  collection, class setup failures, hidden nested children, and cancellation orphans.
- A single indivisible method may exceed900s. Measure before promising feasibility;
  six-way arithmetic alone is not proof.
- Stop on unmatched identities/outcomes, changed assertions/generated bytes/refusals,
  lost negative security cases, unsafe shared state, broken teardown, scope drift, or
  a required production/public contract change. Ask the owner rather than bypass it.
- No session-close, PR10 merge,6351/6160 completion,6512/6530 or6352/6353 execution
  is authorized by this performance work.
